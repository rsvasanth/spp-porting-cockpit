## Seeder drift

The Bridge app's own `legacy_bridge_seeder.py` says `BLANKING_DC_ENTRY` should have **no field mappings** because `populate_blanking_dc_fields()` handles everything. Console's mapping seeder still creates field mappings, including fields that do not match the Legacy child schema (`compound`, `qty`).

The runtime populate function clears engine-created rows and rebuilds them, so the drift may be harmless in practice. It is still confusing and should be tested.

## `populate_blanking_dc_fields`

The populate function is load-bearing:

| Step | Behavior |
|---|---|
| 1 | Read `ctx.items[]`; throw if empty |
| 2 | Set header `employee`, `item_to_produce`, `posting_date` |
| 3 | Use first item for parent `sheeting_clip`, `scan_clip`, `spp_batch_number` |
| 4 | Clear child rows generated by mapping engine |
| 5 | Resolve `bin_code` barcode/name to Legacy `Asset` |
| 6 | Append clean `Blanking DC Item` rows |
| 7 | Reduce/retire Legacy `Item Clip Mapping` by net weight |
| 8 | Populate parent bin/gross/net summary |

## Child row reconstruction

Bridge maps Dash/Console row fields to legacy row fields:

| Dash/Console | Legacy |
|---|---|
| `compound` | `scanned_item` |
| `spp_batch_number` | `spp_batch_number` |
| `bin_code` | `bin_code` as Asset link after resolution |
| `bin_code` | `asset_name` raw barcode/reference |
| `gross_weight` | `gross_weight` |
| `net_weight` | `net_weight` |
| `item_to_produce` | `t_item_to_produce` |
| `sheeting_clip` | `sheeting_clip` |
| `mix_barcode` | `mix_barcode` |

This is why the populate function is the real contract, not the mapping rows.

## Idempotency

Bridge `find_existing_record` checks `Blanking DC Entry.stock_entry_reference == reference_id`. That field is later used by legacy code for created document references too, so verify retries carefully.

## What Hermes workers can change

| Change | Risk |
|---|---|
| Remove Console seeder field mappings | Low/medium if Bridge seeder remains source of truth |
| Modify populate child reconstruction | High; legacy rows depend on it |
| Change clip qty retirement rule | High; affects partial clip consumption |
| Change idempotency field | Medium; `stock_entry_reference` is overloaded |
